# 从这里开始

[项目首页](../README.md) / 使用教程

**先让导航显示出来，再决定是否补全图标。** 不熟悉源码也可以从简单方式开始。

| 你现在的情况 | 推荐入口 | 完成后的标志 |
| :--- | :--- | :--- |
| 刚拿到盒子和 HUD | **[简单方式：只刷盒子](quick-start.md)** | 固定测试与真实导航都能显示 |
| 导航已能显示，想减少图标替代 | **[进阶方式：HUD 补图](hud-upgrade.md)** | 专用新图号正确显示，结束后清屏 |
| 不清楚该下哪一个版本 | [型号与版本选择](versions.md) | 项目号、模块号、底包和文件对应 |
| 碰到搜索、重连或升级问题 | [常见问题](troubleshooting.md) | 记录复现步骤和已脱敏的证据 |

## 简单方式的四个阶段

| 阶段 | 做什么 | 什么时候进入下一步 |
| :--- | :--- | :--- |
| **01 · 核对** | 记录盒子项目号、底包版本和 HUD 模块号 | 与文件标识完全对应 |
| **02 · 刷写** | 用原有刷写工具加载对应镜像 | 盒子重启，CarPlay 正常运行 |
| **03 · 连接** | 搜索 HUD，发送固定转向与车道测试 | 显示正确，约三秒后清屏 |
| **04 · 使用** | 开启自动转发，正式开始导航 | 动作、距离和文字符合现场情况 |

第一次使用保持“完整转向图标”关闭。它不是画质选项，而是切换到需要专用 HUD 资源的新图号。

# 验证范围

原项目已对协议输入、GUI 映射、ARM 后台、CGI、网页与升级包做分层检查。真实 HUD 与真实行驶反馈只覆盖已记录的设备、版本和时间段。

这份公开目录另做源码依赖、链接、隐私/文件清单检查；公共核心只用合成消息测试。FB0 构建工具在相同底包和图像输入下对比交付包 SHA-256，且继续执行原有 Thumb 资源/MD5 校验。

U6A R2c 是当前选用版本，但实体自动连接仍待反馈；FB0 201013 R1 尚待实体升级。不能因为文件校验通过就把 Pre-release 改为已验证稳定版。

详细的本次打包检查结果由 `tools/audit_repo.py` 输出到忽略目录 local-reports，不携带历史行驶日志。

## 这次公开目录的实际重建检查

- 公共转换核心：34 项合成适配边界测试通过，覆盖所有 46 个扩展图号；未使用真实路线日志。

- U6A 完整镜像：从指纹锁定的原厂输入直接组装，文件系统元数据、外层 MD5/CPIO、项目描述和内核保留检查通过。公开构建入口的链接布局不同于原发布版，重建镜像不能冒充原发布版的 SHA-256，且尚未上车验证。
- FB0：仅使用本地 201012 原厂输入、公开 PNG 和复用槽位清单，重新构建得到 SHA-256 `27358bfb627fbc8cb295a5776e324996bce295ca58e7179762880c5e3f89143d`，与交付版一致。391 个原厂记录头、63 项原厂 MCU MD5 接受、篡改拒绝、1024 个主题/动作绘制入口等检查通过。

已脱离个人路径的验证结果位于 reports/。所有无线连接均为模拟；本节不等于新增了实体 FB0 或 R2c 上车验证。

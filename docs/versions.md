# 版本与下载选择

先在设备上核对项目号或 HUD 模块号，再选择对应版本。

| 设备标识 | 版本说明 | 公开构建入口 |
| :--- | :--- | :--- |
| `ly8952` | [**U6A R2c，当前主版本**](../releases/u6a-8952-r2c.md) | [从匹配的 8952 底包构建](build.md#u6a-r2c) |
| `ly8952` | [U6A R2a，实机对照](../releases/u6a-8952-r2a.md) | 历史版 |
| `ly2734` | [U5 R18](../releases/u5-2734-r18.md) | [组件构建](build.md#u5) |
| `HUDBAFB0` | [FB0 201013 R1](../releases/hud-bafb0-201013-r1.md) | [从匹配的 FB0 底包构建](build.md#fb0-专用固件) |
| `HUDBASA0` | [SA0 230928 R3](../releases/hud-basa0-230928-r3.md) | 见[图标资源与适配说明](hud-upgrade.md) |

首发提供源码、教程、图标和构建工具。上表链接是版本说明，完整固件以 Releases 实际挂出的附件为准。

U6A R2a 是回退与对照版本，已有短时实机导航与显示反馈。R2c 基于它修复开机读取配置过早的问题：等待 CarPlay 就绪后恢复设备和开关，配置晚到则继续重试，尊重用户手动关闭。

R2c 的八项后台启动场景、三十项 ARM 接口、六十一项蓝牙和导航模拟场景是既有离线结果；不能替代这次实体设备自动连接验证。R2b 明确停用，不发布为推荐版本。

FB0 补图基于同型号 201012，内部版本为 20201013，增加 40–85 共 46 个槽位；四个仪表主题共用一套 68×68 导航图。尚未确认实体刷写成功。

BASA0 230928 R3 为三主题补图版本，标准 68×68、BM 80×80、MI 82×82。用户曾反馈补图显示效果正常；不表示这份程序适用于 FB0。

各候选成品的字节数、MD5 和 SHA-256 见 [清单](../releases/manifest.json)。对现成固件核对 SHA-256 时，在 Windows PowerShell 运行 `Get-FileHash -LiteralPath '你的固件文件.img' -Algorithm SHA256`。自行构建的 U6A 镜像可能因工具链产生不同哈希，按[构建与验证说明](build.md#u6a-r2c)核对。

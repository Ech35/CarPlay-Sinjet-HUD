## 验证顺序

- [ ] 原厂状态能连接 CarPlay，固件及恢复流程已记录。
- [ ] 电脑环境可回放合成导航数据，输出动作、距离、文字和多车道状态。
- [ ] 新盒子可通过自己支持的接口获得路引，停止导航及断开时收到对应状态。
- [ ] BLE 独立测试能让同一 HUD 显示固定动作及清屏。
- [ ] 台架上完成持续导航、切换地图、重连、掉电启动及清屏。

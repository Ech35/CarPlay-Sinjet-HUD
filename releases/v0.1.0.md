# v0.1.0 · 源码与图文教程首发

仓库包含无线 CarPlay 到信界 HUD 的导航转换源码、适配工具和中文使用教程。这一版补齐手绘原理图、连接示意、车道说明与补图教程。

| 设备 | 当前版本 |
| :--- | :--- |
| U6A `ly8952` | **R2c**，恢复保存的 HUD 配置和自动连接，实机自动连接待反馈 |
| U5 `ly2734` | **R18**，支持按车道编号排序和选择推荐车道 |
| 信界 `HUDBAFB0` | **201013 R1**，46 个扩展图标槽位，已离线校验，待实机刷写 |
